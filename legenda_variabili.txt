Note sulle fonti:
  VEN (ARPAV, XML)      : attributo TYPE di <SENSORE>; valore in <VM>. Ora solare.
  LOM (Lombardia, JSON) : 'tipologia' (anagrafica nf78-nj6b) + 'valore' (dati 647i-nhxk). Ora solare.
  ER  (ARPAE, API)      : descrittore BUFR 'variabile' (Allerta Meteo); t = epoch UTC -> ora solare.
                          Temperatura in Kelvin e pressione in Pascal -> convertite (°C, hPa).
  TN  (Trentino, XML)   : tag-foglia dentro <sezione>/<item>.
  BZ  (Bolzano, JSON)   : campo TYPE (/sensors); valore in VALUE.
  FVG (meteo.fvg, XML)  : tag dentro <meteo_data>.

Note sulle fonti aria:
  VEN : ARPAV aria-json (data.json), coord da coords.json. Ora civile -> solare.
  LOM : ARPA Socrata, anagrafica ib47-atvt (coord) + dati nicp-bhqi (orari), operatore '1'. Ora solare.
  BZ  : APPA, valori airquality/timeseries; COORDINATE da Open Data Hub (EnvironmentStation, APPABZ).
        La dose gamma (GAMMA, µSv/h) e' nello STESSO feed aria di Bolzano -> 4 stazioni sotto AQ_BZ.
  TN  : APPA bollettino JSON (orario). Il feed non ha coordinate -> tabella curata (geocodifica OSM).
  ER  : ARPAE datastore CKAN; join station_id==Cod_staz(senza punti) e variable_id==IdParametro
        con le anagrafiche (coord LAT_GEO/LON_GEO). reftime locale -> solare.
  FVG : SALTATA (dato libero pubblicato con ~7 giorni di ritardo; l'orario e' dietro login).

Note sulle fonti marino-costiere:
  MAR_VEN : CPSM Comune di Venezia (dati.venezia.it), un JSON per grandezza; 'valore' sono stringhe
            ("0.63 m", "209 gradi, 1.4 m/s") -> estrazione numeri. Snapshot ~5 min, accumula.
  MAR_ER  : ARPAE Allerta Meteo, realtime.jsonl (reti 'boa'/'marefe'); descrittori BUFR B22037/B22070/
            B22043/B12101/B13003/B11002 (Kelvin->°C dove serve). date UTC 'Z' -> ora solare. Snapshot.
  ACQ_VEN : ARPAV REST (acqua_boe_stazioni_point per coord GeoJSON, acqua_boe_dati per valori); join su
            CODSEQST, PARAMETRO->sigla, MEDIA=valore, DATA locale -> ora solare. Orario (~1h30 ritardo).
  MAR_FVG : OGS Trieste ERDDAP (nodc.ogs.it), 6 dataset '<ID>_TS' (boa meteo-oceanografica MAMBO1,
            3 ondametri DWRG1/2/3, sensore di portata alla foce Isonzo CURRISO, piezometro/livello
            alla foce Tagliamento PIEZTAG). Coordinate fisse hardcoded (confermate dal .das). QC
            SeaDataNet L20, accettati 0/1/2. time UTC 'Z' -> ora solare. RVFL (portata) a CURRISO
            puo' essere negativa (risalita di marea alla foce): valore reale, non filtrato.
